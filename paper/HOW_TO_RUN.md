# Build the software article

From the repository root, run `make assets` and `make paper`.
The output is `paper/main.pdf`, a two-column author preview using elsarticle.
No private data is required to regenerate the aggregate figure/table.

The structure follows Elsevier's Original Software Publication template:
https://legacyfileshare.elsevier.com/promis_misc/SIMPAC_Article_Template.pdf

The reproducible capsule and software archive DOI remain outstanding.
