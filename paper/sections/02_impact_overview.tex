\section{Impact overview}
The software makes an existing deployment experiment accessible as a small, independently versioned workflow. Its immediate contribution is an executable export-and-measure path and inspectable historical results. Researchers can use it to compare CPU runtimes or device configurations for a fixed estimator and feature schema, before implementing a full filtering service.

The synthetic example removes the need for private research data when checking installation and model conversion. Separating aggregate rendering from measurement also makes clear which outputs can be regenerated from the public repository and which require additional artifacts. No independent user adoption, commercial deployment, or publications enabled by this standalone release have been documented. The linked PhishVN dataset article supplies project context and predates this extraction.
