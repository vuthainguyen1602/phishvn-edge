\begin{abstract}
PhishVN Edge provides scripts for exporting and benchmarking phishing classifiers on Linux edge devices. The standalone release combines scikit-learn-to-ONNX export, ONNX Runtime CPU benchmarking, a synthetic demonstration model, and article-asset generation from aggregate results. A historical NVIDIA Jetson Orin Nano pilot reports median inference latencies of 0.040--0.046 ms for CPU URL detectors and 0.068 ms for a separately prepared TensorRT FP16 engine. The public workflow lets researchers exercise export and inference without private data. Published pilot aggregates support inspection and rendering; reproducing the detector evaluation requires the original models and test data. TensorRT conversion and service integrations remain outside this release.
\end{abstract}
